# 스피넬 하트 발매트 상세페이지 이미지

GitHub Pages로 호스팅해서 쇼핑몰 상세설명에 넣는 용도.

## 순서
| 순서 | 파일 | 내용 |
| --- | --- | --- |
| 1 | 01.jpg | 히어로 ~ 쿠션감 본문 |
| 2 | 02.gif | 쿠션 복원력 테스트 |
| 3 | 03.jpg | 발로 밟는 컷 ~ 흡수력 본문 |
| 4 | 04.gif | 물 흡수 테스트 |
| 5 | 05.jpg | 흡수력 하단 ~ 관리 안내 |

## 사용 방법
1. 이 폴더의 파일을 레포에 업로드
2. Settings → Pages → Branch: main / (root) 저장
3. 몇 분 뒤 `https://<아이디>.github.io/<레포명>/01.jpg` 로 접근 확인
4. `detail.html` 의 src 를 위 주소로 바꿔 상세설명 HTML에 붙여넣기

이미지 폭은 1720px(2배 해상도)입니다. 상세설명 표시 폭은 860px 기준.
