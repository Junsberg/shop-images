# heart — 스피넬 하트 발매트 상세페이지

## 레포 구조
```
shop-images/
└─ heart/
   ├─ index.html          전체 페이지 (미리보기용)
   ├─ detail-11st.html    11번가 HTML편집에 붙여넣을 마크업
   └─ photos/             이미지 14개
```

## 올리는 방법
1. 이 zip 안의 `heart/` 폴더를 레포 루트에 그대로 업로드
2. Settings → Pages → Branch: main / (root) 저장
3. 확인: https://junsberg.github.io/shop-images/heart/index.html

## 11번가 등록
`detail-11st.html` 내용을 셀러오피스 상세설명 → HTML 편집에 붙여넣기.
이미지 src 는 이미 절대경로로 채워져 있습니다.

주의: 11번가 에디터는 외부 웹폰트를 걷어내는 경우가 있어
고운바탕/프리텐다드가 기본 폰트로 대체될 수 있습니다.
